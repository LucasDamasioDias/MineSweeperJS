# MineSweeperJS

This repository contains a personal project developed to study JavaScript, UI, and UX concepts through the implementation of the classic Minesweeper game.

## Project Objectives

The main objectives of this project include:

- Improving JavaScript skills by implementing game logic.
- Enhancing UI/UX knowledge by designing an interactive and intuitive user interface.
- Exploring DOM manipulation and event handling in a web-based application.

## Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**

## Features

- Classic Minesweeper gameplay with adjustable difficulty levels.
- Responsive design for different screen sizes.
- Interactive UI with animations and visual feedback.
- Timer and score tracking.

## How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/LucasDamasioDias/MineSweeperJS.git
   ```

2. Navigate to the project folder:

   ```bash
   cd MineSweeperJS
   ```

3. Open `index.html` in your preferred web browser.

## Project Structure

- `css/` - Contains stylesheets for UI design.
- `js/` - Holds the game logic and event handling.
- `index.html` - Main entry point for the game.
